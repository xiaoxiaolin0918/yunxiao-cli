# sanzhi-yunxiao-cli

Thin npm wrapper for **yunxiao** (Go CLI). Downloads the matching GitHub Release binary.

```bash
npm i -g sanzhi-yunxiao-cli
yunxiao --version
```

Primary path: [GitHub Releases](https://github.com/xiaoxiaolin0918/yunxiao-cli/releases/latest).

Do **not** use npm package `yunxiao-cli` (that is another project, command `yx`).

OIDC publish notes: `docs/wiki/00-process/npm-oidc-publish.md`.
