# 0.16.34

- **feat(workitem/#98) — BREAKING（输出形状）:** `workitem get` 默认不再展开 description。
  - 默认（等同 `--brief`）：`data` 只含 `id` / `serialNumber` / `subject` / `status {id, displayName}` / `assignedTo` / `sprint` / `priority` / `workitemType {id, name}` / `categoryId` / `gmtModified`，以及 `description_summary`（如 `(description: 3214 chars, use --full or --fields description)`，按字符数计；RICHTEXT/HTML 去标签后计数并注明 `chars of text excluding HTML tags`；非字符串 description 也给出提示）；缺失、null 或空串的字段省略。`priority`：非空的顶层 `priority` 原样使用，否则取 `customFieldValues` 中 `fieldId="priority"` 或 `fieldName` 为 `优先级` / `Priority` 的第一个非空值（`{id, displayValue}`，`id` 取 `identifier` 或 `id`）。`meta.projection="brief"`。
  - `--full`：原始 GetWorkitem 对象，`data` 与 `meta` 与 0.16.33 及以前逐字节一致（含分页 meta；不加 `meta.projection`）。
  - `--fields a,b,c`：只保留这些顶层字段（原始值；存在但为 null 的保留为 null；`priority` 同上派生，派生不到为 null 并给 `meta.hint`）。GetWorkitem 字段在该工作项上缺失（如无迭代）输出 null 并列入 `meta.absent_fields`。大小写敏感、去重；空项 / 嵌套路径（`status.id`，请用 `--jq`）/ 非法名在请求前报错；完全未知的名字在读取后报错 `error.subtype=unknown_fields`，`details` 含 `unknown` / `available` / 大小写建议 `suggestions`；响应不是对象（数组 / null）时报 `non_object_response`；报错时 stdout 不输出。`meta.projection="fields"`。
  - `--full` / `--brief` / `--fields` 互斥（`--full=false` 视为未传），冲突在请求前报错（`--dry-run` 同样）。`--dry-run` 不发请求，在 `request.projection` 展示所选视图与来源（`--full` flag 不加该字段）。
  - **兼容开关 `YUNXIAO_WORKITEM_GET_VIEW=full|brief`**：无 view flag 时生效（flag > env > 默认）；旧 CLI 忽略它，需同时兼容新旧 CLI 的脚本用它代替 `--full`。其他取值在请求前报 `invalid_env`。
  - 所有视图保留 `meta.url` / `serial_number` / `resolved_id`（由完整对象计算后再投影）与 `{ok,data,meta}` 信封；API 错误照常透传（`type:"api"`）。
  - **迁移（CLI ≥0.16.34）：** brief 的 `status` **只有** `{id, displayName}`；读取 `.data.status.name` / `.data.status.nameEn` / `.data.description` / `.data.customFieldValues` 等非 brief 字段须加 `--full`（或 `--fields`），或设 `YUNXIAO_WORKITEM_GET_VIEW=full`。`--jq` 作用于投影后的信封。混用新旧 CLI 示例：`yunxiao workitem get X --full 2>/dev/null || yunxiao workitem get X`。拉代码后请执行 `yunxiao skills install --force` 刷新伴生技能。仓库内 skill / 文档未依赖旧的全量输出。
  - 详见 [workitem-get-views](../02-domains/workitem-get-views.md)。
