# 0.16.36

- **fix(npm-publish/#105):** 打 tag 发 Release 之后才刷新 `npm/checksums.txt`，故在 tag 上跑 `npm-publish` 的 `grep yunxiao-cli-${ver}-` **必然失败**。工作流改为：
  - 输入 `tag` 只作版本身份；`ref`（默认 `main`）才是 checkout 目标（须已含刷新后的 checksums）；
  - 校验 `npm/package.json` version == tag（去 `v`）；
  - 校验 `npm/checksums.txt` 含本版条目，并与 GitHub Release 资产 `checksums.txt` 逐字一致；
  - 新增 `dry_run` 输入（`npm publish --dry-run`）；
  - 文档 `docs/wiki/00-process/npm-oidc-publish.md` 写明「tag → Release → checksums PR → publish」顺序；本地脚本 `scripts/npm-publish-verify.sh`。
- Windows CI / CRLF / 仅 Windows 失败测试见 #108（已从本 issue 拆出，本 PR 不改）。
